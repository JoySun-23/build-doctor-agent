### 推荐方案：混合策略（阈值 0.5）

```typescript
async function hybridRAG(log: string) {
  // Step 1: 关键词匹配（零成本，100ms）
  const keywordResults = keywordBasedRetrieval(log, 3);
  const maxScore = keywordResults[0]?.score || 0;

  // Step 2: 决策
  if (maxScore >= 0.5) {
    // 关键词匹配置信度高，直接使用
    console.log('✅ Using keyword-based retrieval (high confidence)');
    return {
      results: keywordResults,
      method: 'keyword',
      cost: 0,
      latency: 100
    };
  } else {
    // 降级到向量检索
    console.log('⚠️ Falling back to vector-based retrieval (low confidence)');
    const vectorResults = await vectorBasedRetrieval(log, 3);
    return {
      results: vectorResults,
      method: 'vector',
      cost: 0.0001,
      latency: 1500
    };
  }
}
```

**效果预测：**
- 准确率：80%（仅比纯向量低 5%）
- 成本：$1,500/月（降低 38%）
- 80% 的请求使用关键词匹配（零成本）
- 20% 的请求降级到向量检索

```typescript
// 缓存策略
const cache = new LRUCache({
  max: 10000,  // 缓存 1 万条诊断结果
  ttl: 1000 * 60 * 60 * 24  // 24 小时过期
});

function getCacheKey(log: string): string {
  // 基于日志指纹生成缓存键
  const fingerprint = extractFingerprint(log);
  return `${fingerprint.errorType}-${fingerprint.errorKeywords.join('-')}`;
}

async function diagnoseWithCache(log: string) {
  const key = getCacheKey(log);

  // 检查缓存
  if (cache.has(key)) {
    console.log('✅ Cache hit');
    return cache.get(key);
  }

  // 缓存未命中，执行诊断
  const result = await diagnose(log);
  cache.set(key, result);
  return result;
}
```

**效果预测：**
- 缓存命中率：30-40%（相似错误重复出现）
- 成本降低：30-40%
- 响应时间：从 12s → 0.5s（缓存命中时）
