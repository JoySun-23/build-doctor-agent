# 面试速查表 - Build Doctor Agent

## 🎯 30秒电梯演讲

"这是一个基于RAG的前端构建错误诊断系统，将诊断时间从10-30分钟缩短至10-30秒，准确率从60%提升至80%。核心技术是检索20个真实Stack Overflow案例，通过向量检索找到最相似的，注入到AI Prompt中生成诊断。技术亮点包括混合检索策略降低60%成本、智能截断减少82% Token、流式响应优化用户体验。"

## ⭐ 5大技术亮点

### 1. RAG检索增强
- 20个Stack Overflow高赞案例
- 向量检索 + 余弦相似度
- Top-3注入Prompt
- **效果**: 准确率60%→80%

### 2. 混合检索策略
- 80%关键词匹配(零成本)
- 20%向量检索(高准确率)
- 混合评分: 向量60% + 关键词40%
- **效果**: 成本降低60%

### 3. 智能日志截断
- 关键词命中 + 滑动窗口
- 上20行 + 下10行
- **效果**: Token减少82%

### 4. 流式响应
- Server-Sent Events
- 首字节<2秒
- **效果**: 用户无等待焦虑

### 5. Serverless优化
- 全局实例复用
- 懒加载初始化
- **效果**: 热启动50-100ms

## 💡 高频问题速答

**Q: 为什么用RAG?**
A: AI容易幻觉(准确率60%)，RAG基于真实案例，准确率80%，可追溯来源

**Q: 如何控制成本?**
A: 混合策略，80%用关键词(零成本)，20%用向量，成本降60%

**Q: 如何处理大日志?**
A: 智能截断，关键词命中+滑动窗口，Token减82%

**Q: 向量检索失败怎么办?**
A: 自动降级到关键词匹配，保证可用性

**Q: 如何扩展知识库?**
A: 手动添加案例，未来可爬虫+用户反馈
